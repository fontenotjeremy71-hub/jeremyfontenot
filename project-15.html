Architecture & execution model

A locally hosted dashboard presents eight administration cards. Seven validated workflows expose Run, Edit, and View Log actions. A custom jf-script:// protocol is routed through a PowerShell launcher, with a shared protocol handler and execution wrapper. Execution results are retained as timestamped logs for repeatable troubleshooting and review.

PowerShell 7Windows administrationMicrosoft GraphEntra IDIntuneWindows LAPSActive Directory

The dashboard is a local administration interface, not a public remote-command service. Its eighth card, portfolio validation, is reserved for integration with the repository's validation suite.
