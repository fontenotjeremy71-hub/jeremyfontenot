# Evidence Control Room Visual Refresh

## Scope

This branch introduces a site-wide visual system that preserves the existing information architecture, evidence wording, proof relationships, and static-site behavior.

## Visual direction

- Evidence Control Room aesthetic using the existing navy, cyan, magenta, green, and amber brand palette
- Page-specific accent identities for Home, Projects, Proof, Dashboard, Resume, Contact, Readiness, and Home Lab
- Stronger hero staging, card hierarchy, evidence inspection surfaces, telemetry presentation, career progression, and contact-page conclusion
- Restrained pointer-responsive ambient lighting and staggered reveal timing
- Explicit reduced-motion and forced-colors fallbacks
- Responsive rules for desktop, tablet, and mobile layouts

## Files

- `assets/css/visual-experience.css`
- `assets/css/site.css`
- `assets/js/site.js`

## Boundaries

No public technical claim, evidence classification, proof link, metric source, limitation, canonical URL, metadata record, or navigation destination is changed by this visual refresh.
