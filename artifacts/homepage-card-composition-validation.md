# Homepage Visual Validation Scope

The pull request must pass the existing repository validation workflow at the exact head commit.

Required checks:

- Responsive visual review across the repository viewport matrix
- Chromium page validation
- No clipped text or broken controls
- No horizontal overflow
- Accessibility and reduced-motion behavior
- Lighthouse, SEO, sitemap, internal-link, evidence, and publication validation

The correction is release-ready only after the complete workflow succeeds.
