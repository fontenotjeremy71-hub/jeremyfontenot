# Homepage Evidence Visualization Scope

## Purpose

Provide a meaningful, original visual for the featured Evidence-backed Capability card without introducing decorative or unsupported technology claims.

## Included verified systems

- Proxmox VE virtualization
- pfSense firewall, routing, and segmentation
- DC01 Windows Server
- Active Directory Domain Services
- DNS
- DHCP
- Group Policy
- WS01 Windows client validation
- Linux01 Ubuntu on VLAN 30
- Scheduled backup coverage
- Isolated restore validation
- Operational inventories, runbooks, and validation output

## Excluded claims

The visualization does not represent production ownership, enterprise scale, high availability, formal disaster-recovery assurance, unsupported cloud management capability, or client-system administration.
