# Readiness Alignment Validation Scope

The correction is release-ready only after the exact pull-request head passes:

- repository architecture and publication validation;
- Chromium page validation;
- responsive visual review at the repository viewport matrix;
- no clipped text, broken controls, or horizontal overflow;
- accessibility and reduced-motion checks;
- Lighthouse, SEO, sitemap, and internal-link validation;
- evidence hash, claim, and metadata checks.
