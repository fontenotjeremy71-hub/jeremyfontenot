ServiceNow: invalid assignee reference

Group membership did not make a Procurement user selectable. The Task assigned_to reference qualifier required the itil role. Granting that lab role resolved the invalid reference while retaining the qualifier.

Environment

Personal ServiceNow Developer Instance with separate Procurement and Field Services lab identities and role-qualified task assignment.

Diagnostic process, findings & corrective action

Group membership did not make a Procurement user selectable. The Task assigned_to reference qualifier required the itil role. Granting that lab role resolved the invalid reference while retaining the qualifier.

Validation & outcome

Closing the Field Services task automatically completed the RITM and parent REQ. Procurement, delivery, installation, and handoff remained simulations.

Lessons & limitations

Personal ServiceNow PDI. Physical laptop procurement, vendor delivery, software installation, and user handoff were simulated. The project demonstrates ServiceNow workflow understanding and hands-on lab administration, not employer production ownership.

The evidence supports the specific scenario. Unestablished root causes are not presented as confirmed.
