Troubleshooting case study

Graph: 400 and 403 responses

A directory-role membership request returned 400 because it used an unsupported $top parameter. A signInActivity query returned 403 until the missing AuditLog.Read.All delegated scope was addressed.

Environment

Microsoft 365 E5 Developer tenant; Microsoft.Graph.Authentication, delegated Device Code authentication, Graph v1.0 GET requests, and local CSV reports.

Diagnostic process, findings & corrective action

A directory-role membership request returned 400 because it used an unsupported $top parameter. A signInActivity query returned 403 until the missing AuditLog.Read.All delegated scope was addressed.

Validation & outcome

Seven read-only scripts and CSV reporting are documented as validated. Live exports are deliberately excluded from the public repository.

Lessons & limitations

Read-only delegated administration/reporting is currently proven. Live CSV exports are intentionally not public because they may contain UPNs, object IDs, device identifiers, and tenant-specific data. Do not imply write automation or broader Graph coverage that has not been validated.

The evidence supports the specific scenario. Unestablished root causes are not presented as confirmed.
