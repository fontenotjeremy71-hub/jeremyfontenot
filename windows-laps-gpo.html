Validated Microsoft systems administration project

Windows LAPS & Advanced Group Policy

Deployed modern Windows LAPS in a Windows Server 2022 Active Directory lab using schema validation, a dedicated workstation OU, Group Policy, encrypted password storage, least-privilege delegation, RSOP, event logs, and forced password rotation.

Windows LAPSActive DirectoryGroup PolicyPowerShellWindows Server 2022Windows 10

Architecture

Isolated scope with explicit delegation.

AD

Schema and OU

Validated that LAPS schema attributes were absent, extended the schema on DC01, then scoped WS01 to a protected LAPS-Test OU beneath Workstations.

GPO

Policy

Backs passwords to AD, manages LocalAdmin, rotates every 30 days, uses 14-character complex passwords, enables expiration protection, and stores the password encrypted.

ACL

Least privilege

Computer self-permission was delegated to the OU and password-read permission was assigned to GG-LAPS-Password-Readers. A non-admin reader account proved delegated access.

VAL

Validation

gpresult, GUI RSOP, LAPS Operational events, AD attributes, encrypted retrieval, a negative-access control, and forced rotation all produced expected results.

Validated results

End-to-end LAPS behavior was observed.
