Architecture

One lab, multiple operating systems and Microsoft management layers

The environment centers on pfSense networking, Windows Server Active Directory, Hyper-V, SCVMM, Windows Admin Center, Azure Arc, Linux, macOS, backup, and restore assurance. Proxmox provides the underlying virtualization platform for several lab systems.

Systems

Cross-platform systems supporting Microsoft administration

Core systems include DC01, WS01, HVHOST01, VMM01, APP01, Linux01, macOS, and pfSense. Each system has a defined role and is documented as lab infrastructure, not production enterprise ownership.

Operations

Identity, networking, remote administration, backup

Operational work includes AD DS, DNS, DHCP, WinRM, RDP, Windows Admin Center, virtualization networking, pfSense rules, OpenVPN access, backup schedules, and restore validation.

Restore validation

Backup archives were exercised, not just created

Restore assurance is treated as an operational control. Validation focuses on recoverability, isolated testing, service checks, and documented evidence.

Scope and limitations

Personal-lab validation, not production ownership

The evidence documents a bounded lab. Restore results include both narrow PASS and INCONCLUSIVE outcomes; no disaster-recovery readiness, RTO, RPO, clustering, or high-availability claim is made.
