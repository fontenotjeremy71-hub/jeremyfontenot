## Conflict resolution

Repository agent profiles originally require stopping after one phase and prohibit agent merges. The owner-approved completion program narrowly supersedes those two constraints, authorizing sequential continuation and exact-head protected merges. All stricter evidence-preservation, security, validation, provenance, claim-boundary, branch-isolation, accessibility, publication-safety, and review requirements remain binding.
