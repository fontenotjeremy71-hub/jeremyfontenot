Configuration and troubleshooting workflow

1. Installer recovery

Identified a repeated signer-certificate import failure in the WAC installer, traced it to the Windows PowerShell security module, and successfully relaunched the installer through Windows PowerShell 5.1.

2. Local gateway configuration

Installed the Windows Admin Center service, generated a lab self-signed TLS certificate, validated TCP 6600 listening state, and set the service startup type to Automatic.

3. Remote management path

Enabled WinRM where required and added scoped pfSense OpenVPN rules from 10.10.40.0/24 to TCP 5985 on the managed Windows systems.

4. Credential and access remediation

Used domain credentials for server connections, diagnosed an account lockout, verified group membership, restored access, and refreshed Windows Admin Center connection credentials.

5. Hyper-V management

Validated the HVHOST01 overview, APP01 virtual-machine inventory, and the External-LAN virtual switch through Windows Admin Center.

6. Post-change validation

Used the APP01 PowerShell tool, confirmed a genuine pending restart, restarted the server through WAC, and verified that all reboot indicators cleared.
