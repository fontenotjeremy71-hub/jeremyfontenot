# Evidence Library

This directory preserves the technical artifacts supporting the portfolio.

The evidence library is intentionally broader than the recruiter-facing website. The public site points reviewers to curated proof while historical and lower-level artifacts remain preserved here.

## Evidence policy

- Preserve original technical evidence whenever safe.
- Publish only sanitized evidence.
- Never expose passwords, authentication tokens, private keys, VPN credentials, recovery keys, or Windows LAPS password values.
- Distinguish direct validation from documentation, configuration, simulation, and inconclusive results.
- Do not delete evidence simply because a project is no longer featured prominently.
