Scope

Personal Microsoft 365 developer tenant

This project uses a personal Microsoft 365 developer tenant to demonstrate bounded messaging, security, identity, and licensing administration. The work is documented as lab validation and does not claim production tenant ownership, enterprise mail-flow responsibility, or organization-wide security authority.

Exchange Online

Shared mailbox, distribution group, transport rule, and message trace

A shared mailbox was configured with Full Access, Send As, and Send on Behalf delegation. A distribution group was created and validated with member delivery. An external-sender transport rule was enabled in Enforce mode and functionally validated through message trace and subject tagging.

Microsoft Defender

Baseline mail protection and message investigation

Anti-malware, Safe Attachments, Safe Links, anti-phishing, quarantine, and Explorer views were reviewed. Explorer evidence confirms visibility of the Project 3 test messages, including the external-sender validation message.

Conditional Access

Troubleshoot the policy result, correct scope, then validate

An internal test user was blocked with sign-in error 53003 because a security-information registration block policy intended for external identities was scoped to all users. Sign-in details and policy evaluation identified the cause. The policy was changed to guest or external users, the audit log recorded the successful update, and a later My Apps sign-in succeeded while MFA still evaluated successfully and the block policy no longer applied.

Licensing

Effective Developer E5 assignment with discrepancy preserved

A dedicated security group was used for Developer E5 licensing. Microsoft 365 Admin Center showed the group assignment with zero licensing errors and zero members without licenses, and the test user held an active effective E5 license. Microsoft Graph returned conflicting assignment metadata, so the discrepancy is explicitly documented instead of being presented as reconciled.

Troubleshooting

Evidence before resets or rebuilds

The project preserved working Exchange and identity configuration while using sign-in logs, Conditional Access evaluation, audit logs, message trace, Defender Explorer, and Graph responses to isolate issues. Exchange Online and Microsoft Graph were also kept in separate PowerShell processes after an assembly-version conflict was identified.

Microsoft Entra Conditional Access

Problem observed

Status: REMEDIATED

The Project 3 License Test account authenticated successfully but received sign-in error 53003 because Conditional Access blocked access.

Sign-in analysis showed two relevant policy evaluations:

  • Multifactor authentication for Microsoft partners and vendors — Failure during the blocked attempt
  • Security info registration for Microsoft partners and vendors — Failure with Block

The security-info registration policy was incorrectly scoped to All users, causing an internal tenant member to hit a policy intended for external/partner identities.

Remediation

Status: COMPLETE

Policy scope changed from:

  • Include: All users

to:

  • Include: Guest or external users
  • All six external identity categories selected
  • External Microsoft Entra organizations: All

The existing emergency-access exclusions and trusted-location behavior were preserved.

Group assignment

Status: COMPLETE in Microsoft 365 Admin Center / Graph metadata discrepancy documented

Microsoft 365 Admin Center shows:

  • Group: Project 3 E5 Licensing
  • Type: Group
  • Developer E5 product selected
  • Group apps and services available for management
  • Licensing errors: 0
  • Members without licenses: 0

However, Microsoft Graph repeatedly returned:

  • Group assignedLicenses: []
  • Group licenseProcessingState: null
  • User assignedByGroup: null

An attempted direct removal of the user license returned the service error that the license was inherited from group membership. Because the Microsoft 365 licensing UI and service behavior contradict the Graph metadata, the discrepancy is preserved as a troubleshooting finding.
