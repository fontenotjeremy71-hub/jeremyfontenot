# Jeremy Fontenot — static IT portfolio

This folder is a complete static website. Every content page is literal HTML. Shared CSS and a small vanilla JavaScript file provide styling, an accessible mobile menu, and optional evidence filtering. No build command, dependency installation, framework, generator, database, or backend is required.

## Review locally

Unzip the package, open `index.html` in a browser, and follow the relative links. Documents may open in the browser or download according to browser settings. Case studies are in `projects/<slug>/index.html`.

## Upload when approved

Upload the contents of this folder to a static host's document root, preserving paths and filename case. Configure the host's document index as `index.html` and its missing-page document as `404.html`. A host can serve this folder directly; no CI workflow is supplied or required.

The included sitemap assumes the owner's existing domain, `https://jeremyfontenot.online`. If a different domain is chosen, update the sitemap URLs and robots.txt sitemap location. Review custom-domain settings with the chosen host and the domain registrar before making any DNS changes. No deployment or DNS change was performed for this delivery.

## Evidence and source preservation

Retained evidence downloads, portrait, logo, favicon, resume, and lab document were copied without changing their bytes. Text files containing PowerShell code are inert evidence downloads, not website programs. Existing download aliases are preserved.

Evidence types and limitations appear in the case studies. Sanitized records are not represented as raw transcripts. SharePoint HTML derivatives are not authenticated originals and do not establish technical implementation. No ASPX is presented as a functioning static HTML page.

The supplied reorganized repository ZIP remains the unchanged preservation source for all 3,525 retained originals, including the separate ASPX and HTML collections. The site exposes curated direct evidence; it does not turn every preserved source document into a public page. Refer to the separate completion report and proof register for audit details.

Employment and credentials follow the supplied resume, not independently verified HR or issuer records. Original documents may contain older embedded labels and links. These have not been rewritten.

`URL-REDIRECT-MAP.csv` documents preserved aliases. Static redirects use refresh metadata and a visible fallback link. A static site cannot impose server response codes; host-level 301 rules are optional future configuration.
