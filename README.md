## Evidence policy

Technical evidence is preserved rather than deleted for cosmetic cleanup. Public evidence is sanitized and never intentionally includes passwords, tokens, VPN credentials, private keys, recovery keys, or managed LAPS password values.

Professional employment experience and personal-lab systems administration are presented separately and accurately.
