On-Premises Microsoft Home Lab

Practical administration. Documented results. Original technical evidence.

ImplementationTroubleshootingValidation and proof

Objective and implementation

Build an inspectable Windows infrastructure lab and document a bounded restore exercise. Technologies: Windows Server 2022, AD DS, DNS, DHCP, Group Policy Management, Proxmox, and Linux.

The sanitized DC01 inventory derivative records the installed roles and domain configuration. The restore derivative describes an isolated Linux01 drill from VM 400 to temporary VM 401, guest boot and agent response, and cleanup.

Troubleshooting and operational limits

The restore summary retains thin-pool risk and states that a per-command restore transcript is not included. Upstream raw inventory and restore records are referenced by commit and hash but are not independently supplied. The source set includes PASS, narrow PASS, and INCONCLUSIVE outcomes; one drill does not establish comprehensive disaster recovery.

Scope and limitations

Personal nonproduction lab. Does not prove enterprise production ownership, HA, clustering, S2D, production DR readiness, RTO/RPO, SLA performance, or continuous availability. Restore testing contains PASS, narrow PASS, and INCONCLUSIVE results and must remain represented as such.

Registry status retained in the audit: COMPLETE — validated portfolio scope; the lab itself remains an ongoing environment. . Evidence below is assessed by artifact type; this package does not rerun the lab.
