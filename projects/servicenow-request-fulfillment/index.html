Objective and implementation

Document the relationship between a catalog request, requested item, approval, sequential fulfillment tasks, and automatic closure in a ServiceNow Personal Developer Instance. Technologies: Service Catalog, REQ/RITM/SCTASK, assignment groups, roles, and Service Operations Workspace.

The README describes Procurement and Field Services tasks, impersonated fulfillment, backorder tracking, and automatic stage transitions. Vendor delivery, endpoint deployment, software installation, and handoff were lab simulations.

Troubleshooting and evidence limits

The README identifies an Assigned to reference qualifier requiring the itil role. Group membership alone did not resolve assignee selection; adding the role did. The document reports automatic RITM and REQ closure, but no independent PDI audit export or execution capture is supplied. These are documentary results, not a rerun workflow.

Scope and limitations

Personal ServiceNow PDI. Physical laptop procurement, vendor delivery, software installation, and user handoff were simulated. The project demonstrates ServiceNow workflow understanding and hands-on lab administration, not employer production ownership.
