Microsoft 365 Graph Administration Lab

Personal-lab portfolio project · exact claim boundaries and direct retained proof

ImplementationTroubleshootingValidation and proof

Objective and implementation

Build reusable read-only Microsoft 365 reporting in PowerShell. Technologies: Microsoft.Graph.Authentication, delegated Graph scopes, REST GET requests, hashtable response handling, and CSV export.

The seven retained scripts cover tenant inventory, users, groups, licensing, directory roles, stale accounts, and Intune managed devices. Script inspection confirms reporting implementation. The tenant summary reads first-page collections without pagination for several counts; it is not presented as a complete large-tenant inventory solution.

Troubleshooting and code review

The notes document a role-members query returning 400 with a top parameter and a signInActivity request returning 403 without AuditLog.Read.All. The role script omits the problematic top parameter; stale-account and Intune scripts compare required scopes and reconnect. No scripts were executed against a tenant during this review. Successful live CSV generation remains source-reported because raw output is withheld.

Scope and limitations

Read-only delegated administration/reporting is currently proven. Live CSV exports are intentionally not public because they may contain UPNs, object IDs, device identifiers, and tenant-specific data. Do not imply write automation or broader Graph coverage that has not been validated.

Registry status retained in the audit: COMPLETE — validated read-only Microsoft Graph administration and reporting automation. . Evidence below is assessed by artifact type; this package does not rerun the lab.
