Azure Arc Hybrid Windows Management

Practical administration. Documented results. Original technical evidence.

ImplementationTroubleshootingValidation and proof

Objective and implementation

Document hybrid Windows and SQL inventory through Azure Arc in a personal lab. Technologies: Azure Arc Connected Machine agent, Windows Server 2022, SQL Server 2022 Developer, PowerShell remoting, and Windows Admin Center.

The public-safe summary records Connected agent state for HVHOST01 and VMM01. Direct HVHOST01 checks report three running Arc services and successful outbound TCP 443. Portal/WAC observations record VMM01 and its SQL extension and inventory.

Troubleshooting and access limits

VMM01 answered WinRM, but the credential was rejected for remote PowerShell. The local Arc/SQL services were not reread during that collection. The source explicitly distinguishes those unavailable checks from portal observations. Automatic backups are recorded as Disabled.

Scope and limitations

Supports two Arc-connected Windows Server lab machines and one SQL Server 2022 Developer instance. Does not prove production Azure administration, broad RBAC ownership, HA/DR, SLA performance, or enablement of Azure services not explicitly shown.

Registry status retained in the audit: COMPLETE . Evidence below is assessed by artifact type; this package does not rerun the lab.
