Objective and implementation

Demonstrate a bounded Windows LAPS access and rotation workflow in a personal AD lab. Technologies: Windows LAPS, Active Directory, Group Policy, and PowerShell.

The retained schema output lists modern msLAPS attributes. The retrieval result identifies an EncryptedPassword source, successful decryption, and the delegated reader group. Password values are intentionally absent.

Troubleshooting and control checks

Compare authorized retrieval with the standard-user negative test. The latter returned no LAPS record through the tested path. The rotation record identifies events 10014, 10020, 10018, and 10004. These sanitized results support the specific tests below; broader GPO configuration is not independently reconstructed here.

Scope and limitations

Personal Active Directory lab. The linked sanitized records support modern schema attributes, authorized encrypted retrieval, the tested negative access path, and recorded forced-rotation events. Actual passwords are excluded.

Registry status retained in the audit: COMPLETE . Evidence below is assessed by artifact type; this package does not rerun the lab.
